# 전공체육 중등임용 스터디 OS (2027학년도 경북·포스코 대비)
> **"기출을 모으는 곳이 아니라, 출제자의 관점으로 전공체육을 구조화하는 학습 시스템"**
> 2027학년도 중등 체육교사 임용시험(경상북도 교육청) 및 포스코교육재단(포항제철중·고) 정규 교사 채용 대비 80점 만점 개인화 학습 OS

## 1. 2027학년도 체육교과 출제위원 관점 핵심 정책 변화
1. **2022 개정 체육과 교육과정 전면 적용 (2025~2027년 고등학교 전 학년 정착)**:
   - **3대 신체활동 형식**: 2015 5대 생활영역(건강/도전/경쟁/표현/안전)에서 신체활동 본연의 가치인 **운동, 스포츠, 표현**의 3대 형식으로 전면 개편.
   - **3대 신체활동 역량**: **움직임 수행 역량, 건강관리 역량, 신체활동 문화 향유 역량**.
   - **3차원 내용체계**: **지식·이해 / 과정·기능 / 가치·태도**의 3차원 입체화.
   - **이론적 근거**: **기본움직임기술(FMS: 이동, 비이동, 조작 기술)**과 갈라휴(Gallahue)의 생애주기 운동발달 단계 접목.
2. **80점 만점 시험 구조 및 90분 시간 전략**:
   - **1교시 (전공 A, 90분, 40점)**: 단답형 4문항(8점) + 서술형 8문항(32점) = 12문항
   - **2교시 (전공 B, 90분, 40점)**: 단답형 2문항(4점) + 서술형 9문항(36점) = 11문항
   - **전체 합계**: 단답 6문항(12점) + 서술 17문항(68점) = 23문항, 80점 만점
3. **포용적 체육(Inclusion PE) 및 수업설계**:
   - 특수교육대상학생 및 운동 기능 하위 학생을 위한 보편적 학습설계(UDL), STEP(Space, Task, Equipment, People) 수정 모델, TPSR 사회적 책임감 모형 실천.

## 3. 실행 방법 (더블클릭 즉시 실행)
본 애플리케이션은 현대 브라우저 기술(HTML5, Vanilla CSS, Modern ES6+, LocalStorage, Canvas 2D, Web Audio API)로 독립 패키징되어 있어 별도의 복잡한 웹 서버 구축 없이도 즉시 작동합니다.

1. `g:\내 드라이브\임용고\pe-imyong-study.html` 파일을 Chrome, Edge, Safari 등의 브라우저로 열거나 더블클릭합니다.
2. 상단 메뉴 및 좌측 사이드바(모바일은 하단바)를 통해 15개 모듈을 자유롭게 탐색할 수 있습니다.
3. 모든 학습 진행 상황(체크박스, 답안 작성본, 오답노트, 순공 시간)은 브라우저 LocalStorage에 안전하게 자동 저장됩니다.
